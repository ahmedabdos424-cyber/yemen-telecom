## 7 Failing Tests — Root Cause

All 7 failures are in `src/__tests__/auth.test.ts`. They fail with:

```
TypeError: Cannot read properties of undefined (reading 'clear')
  at src/__tests__/auth.test.ts:11:18
```

**Root cause:** The test file uses `localStorage.clear()` in `beforeEach`, but the jsdom environment does not provide `localStorage` by default. Vitest requires `--localstorage-file` flag or explicit mocking.

**This is an environment configuration issue, NOT a test logic failure.** The test code is correct — it simply needs `localStorage` to be available.

**Fix:** Either:
1. Add `localStorage` mock to `src/__tests__/setup.ts`
2. Or add `@vitest-environment jsdom` directive (already present but jsdom needs `--localstorage-file`)
